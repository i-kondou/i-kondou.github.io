  1. 2026.10 プレプリント

    Rethinking SZZ Search Strategiesのプレプリントを公開

    論文「Rethinking SZZ Search Strategies: Lessons from Claude Code」をarXivで公開しました。現在査読中（Under review）です。 Claude Codeによるバグ混入コミットの特定精度と調査過程を分析し、SZZ手法の探索戦略を検討した研究です。

  2. 2026.09 受賞

    MV-SZZの論文が卓越研究賞を受賞

    論文「MV-SZZ: An Empirical Study of a Majority Voting-Based SZZ Method」が、 情報処理学会ソフトウェア工学研究会の卓越研究賞を受賞しました。近藤将成氏、Daniel M. German氏、亀井靖高氏、肥後芳樹氏との共同研究による受賞です。

    論文の詳細 関連リンク
  3. 2026.09 ポスター発表

    SES 2026にて英語ポスター発表

    神奈川県横浜市の慶應義塾大学日吉キャンパスで開催されたソフトウェアエンジニアリングシンポジウム2026（SES 2026）の学生国際英語ポスターセッションにて、 「Can Claude Code Find Bug-Inducing Commits? An Empirical Study of Identification, Investigation, and Justification」を発表しました。 Claude Codeによるバグ混入コミットの特定と、調査過程・根拠の説明を扱った研究です。

    発表の詳細 関連リンク
  4. 2026.07 研究会発表

    SIGSS / SIGSEの合同研究会にて研究発表

    北海道札幌市で開催されたソフトウェアサイエンス研究会（SIGSS）・ソフトウェア工学研究会（SIGSE）などの合同研究会にて、 「バグ混入コミットによる過去制約違反の実証研究」を発表しました。 バグが混入する変更と、それ以前のプログラムが満たしていた制約との関係を調べた研究です。

    発表の詳細 関連リンク
  5. 2026.05 プレスリリース

    MV-SZZの研究成果をプレスリリースで紹介

    大阪大学と九州大学から、MV-SZZの研究成果に関するプレスリリースが公開されました。 開発履歴をトークン単位で追跡し、多数決を組み合わせてバグ混入コミットを特定する手法を紹介しています。

    論文の詳細 関連リンク
  6. 2026.05 オンライン公開月 論文採択

    MV-SZZの論文がTSEに採択・公開

    論文「MV-SZZ: An Empirical Study of a Majority Voting-Based SZZ Method」が、 IEEE Transactions on Software Engineering（TSE）に採択され、オンライン公開されました。 トークン単位の開発履歴と多数決を組み合わせる手法を提案し、バグ混入コミットの特定精度を評価した研究です。
